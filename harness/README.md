# harness/: the game engine

The Python package that runs one game: logit demand and payoffs (`economics.py`), the scripted spy and its frozen messages (`spy.py`, `conditions.py`), the LLM seller agent and API clients (`agent.py`, `clients.py`), the round loop and logging (`runner.py`, `runlog.py`), and the say/do labels and detectors (`labels.py`, `metrics.py`, `detectors.py`).

Start with `runner.py`.
